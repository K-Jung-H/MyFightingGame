## Network Synchronization Milestone (Agile 4-Phase)

본 프로젝트는 결정론적 고정 틱(Deterministic Fixed-Tick) 기반의 롤백 넷코드(Rollback Netcode)를 목표로 하며, 빠른 검증을 위해 4단계 애자일(Agile) 마일스톤으로 나누어 네트워크 동기화를 구현한다.

* **Phase 1: 로컬 더미 패킷 송수신 (연결 검증)**
  * **목표:** 로비 및 매칭 시스템을 배제하고 순수 P2P(UDP) 통신망의 정상 연결 여부를 확인한다.
  * **구현:** `Unity.Networking.Transport`를 사용하여 Host와 Client 구조를 세팅한다. 로컬호스트(127.0.0.1) 환경에서 클라이언트 간 단순 틱(Tick) 번호나 더미 바이트 배열을 교환하며 패킷 송수신과 네트워크 지연(Ping)을 측정한다.

* **Phase 2: 로컬 딜레이 넷코드 (입력 데이터 교환)**
  * **목표:** 실제 게임 루프에 네트워크 입력을 결합하여 원격 캐릭터 제어를 구현한다.
  * **구현:** 순수 텍스트 대신 `InputFlags`와 `currentTick` 구조체를 직렬화하여 송수신한다. `GameLoopManager`를 수정하여 로컬 입력과 수신된 원격 입력이 모두 준비될 때까지 시뮬레이션 틱 연산을 대기(Delay)시키는 기초적인 동기화 모델을 완성한다.

* **Phase 3: 롤백(Rollback) 시스템 도입 (상태 복원 및 동기화)**
  * **목표:** 네트워크 지연 발생 시 게임이 멈추는 현상을 해결하고, 예측(Prediction)과 롤백을 통해 부드러운 조작감을 확보한다.
  * **구현:** 패킷 지연 시 이전 프레임 입력을 복사하여 예측 시뮬레이션을 진행한다. 예측이 틀린 과거 패킷이 도착할 경우, `GameLoopManager`를 과거 상태로 되돌린 후(Load State) 빠르게 재연산(Fast-forward)하여 현재 틱으로 복구하는 `RollbackManager`를 구축한다.

* **Phase 4: UGS Relay 및 로비 매칭 (최종 온라인 환경 통합)**
  * **목표:** 로컬호스트 하드코딩을 제거하고, 인터넷 환경에서 실제 유저 간 매칭 및 통신을 지원한다.
  * **구현:** Unity Gaming Services(UGS)의 `Relay` 모듈을 연동하여 IP 직접 노출 없이 P2P 통신을 중계한다. 이후 `Lobby` 서비스를 통합하여 방 생성, 검색, 참가 기능을 갖춘 완성된 온라인 격투 게임 환경을 구축한다.
