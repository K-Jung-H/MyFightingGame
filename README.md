롤백 시스템의 무결성을 유지하기 위해 시각적 동기화, 연출 중복 방지, 데이터 리셋이라는 세 가지 관점에서 코드를 보완

* 라운드 리셋 시 파편 초기화 - GameLoopManager에서는 실제 시간선이 흐를 때만 연출을 실행하고, 롤백 후에는 뷰를 물리 상태에 강제 고정
* 롤백 재연산 중 시각 연출 차단 - OnWallBroken 콜백 과정에서 simState.isResimulating을 체크하여 연출 중복 호출을 방지
* SyncVisuals의 엄격한 가시성 동기화 - 롤백으로 인해 벽이 다시 생겨나는 상황을 대비하여, 매 프레임 비트마스크를 기반으로 벽 메쉬 상태를 갱신



현제 문제 상황:

* WallBounce가 아니라 플레이어가 접촉만 해도 WallBreak 진행 중 + 오류코드 발생 중
* 라운드 종료 시, WallBreak 파편이 제거 안되고 있음
* Stage 크기에 따른 카메라 움직임에 대한 개선 필요
